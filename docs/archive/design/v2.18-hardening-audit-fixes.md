## 1. Problem

Automated deep-code audit (2026-07-03) surfaced 9 issues at 🔴 critical and 🟡 high/medium severity in three families:
1. **Reliability bugs** — proxy subscriber leaks exhausting connection slots, silent data loss from object-store sweep, brittle array splicing in compaction.
2. **Error-handling bugs** — `catch return` voiding `errdefer` chains, manual field-by-field deinit leaking on struct growth, `nowMillis` returning 0 silently degrading timing guards.
3. **Test-coverage gaps** — zero integration tests for run-mode drivers, zero dedicated tests for partial-JSON parser, missing completeness assertions on object-store sweep.

Proxy subscriber leak and grep `\b` issue reproduced in the wild (documented in `docs/todos/todos.md`).

## 2. What already exists

### 2.1 Proxy subscriber management (`src/agent/proxy.zig`)

- Each HTTP client creates a `Subscriber` struct (~lines 350-380).
- `fanOutLocked` broadcasts events; on write failure sets `sub.closed = true` but does NOT shut down read side.
- Reader thread blocks on `readVec` waiting for data/FIN.
- If client disconnects without FIN/RST (browser background tab, OS half-close), `readVec` never returns, `defer removeSub` never runs.
- After ~32 cycles (`max_subs = 32`), all slots exhausted → no new connections until restart.

### 2.2 Object store (`src/coding/object_store.zig`)

Content-addressed blobs ≥32 KiB spilled to `objects/<hex[0..2]>/<hex[2..]>`. `sweep()` (lines 102-115) walks directory tree, checks membership against `keep` list, deletes orphans. If caller misses a ref in `keep` list, orphaned blob deleted → subsequent reads fail with `error.ObjectNotFound`.

### 2.3 Grep tool regex (`src/coding/tools/grep.zig`)

Zig's regex engine is ECMAScript subset — does NOT support `\b` (word boundary). Models reliably emit `\b` in patterns. Returns `grep_bad_regex` with unactionable suggestion. Bug documented in `docs/todos/todos.md`.

### 2.4 `catch return` voiding `errdefer` (`agent/loop.zig`, `agent/agent.zig`)

`errdefer` fires only when current function returns error via error-union path. `catch return` in void/non-error-returning function does NOT trigger `errdefer` — function returns normally. Pattern appears in agent code with `errdefer` after `catch return` — dead code.

### 2.5 `freeSessionHeader` fragile (`src/coding/session.zig:136-146`)

`SessionHeader` has 7 owning `[]const u8` fields. `freeSessionHeader` manually frees each by name. Adding a new owning-string field silently leaks unless `freeSessionHeader` also updated. No compile-time check.

### 2.6 Mode-level integration tests missing

Four run-mode drivers (`print.zig`, `interactive.zig`, `rpc.zig`, `proxy.zig`) have zero integration tests. CLI argument parser tested extensively, but mode-entry functions never exercised end-to-end.

### 2.7 `nowMillis()` returns 0 on error (`src/ai/stream.zig:36-53`)

Two code paths: Linux `clock_gettime` direct syscall, POSIX libc `clock_gettime`. Both return 0 on failure. Callers use `nowMillis()` for elapsed time → garbage calculations when 0 returned. In practice only libc path (macOS/BSD) can fail.

### 2.8 Compaction `replaceSpanWithSummary` manual `memcpy` (`src/coding/compaction.zig:556-566`)

Manual `std.mem.copyForwards` for transcript splice — correct for current call sites but brittle. Single off-by-one corrupts transcript silently. No invariant check.

### 2.9 Partial JSON parser (`src/ai/partial_json.zig`)

Complex state machine for streaming tool-call argument parsing. Critical for correct streaming — has been site of past bugs (DeepSeek-specific parse failures). **No dedicated unit tests.** Coverage entirely indirect through provider integration tests.

## 3. Proposed fixes

### 3.1 [🔴] Fix proxy subscriber slot leak — Wave 1

**Target:** `src/agent/proxy.zig`

**Approach:** When `fanOutLocked` sets `sub.closed = true`, also shut down read side of TCP socket via `std.posix.shutdown(sub.fd, .RECV)`. Forces reader thread's `readVec` to return immediately, `break` fires, `defer removeSub` runs. Add `shutdown_on_close: bool` field to `Subscriber` (true for SSE subscribers, false for internal).

**Testing:** Proxy-mode integration test: open SSE connection, read one event, close socket without graceful FIN, open second connection, assert receives events without `subscriber.refused`.

**LOC:** ~10 lines proxy.zig + ~50 lines test.

### 3.2 [🔴] Harden object store `sweep` — Wave 1

**Target:** `src/coding/object_store.zig`, `src/coding/session.zig`

**Approach A (recommended):** Before calling `sweep`, re-read every `Ref` in transcript and assert its hash is in `keep`. Makes invariant explicit; catches call-site bugs in debug/release-safe. `std.debug.assert` stripped in ReleaseFast.

**Testing:** Write objects, write transcript referencing only some, run sweep with incomplete keep list, assert assertion catches it.

**LOC:** ~10 lines session.zig + ~60 lines test.

### 3.3 [🔴] Handle grep regex `\b` gracefully — Wave 2

**Target:** `src/coding/tools/grep.zig`

**Approach A (recommended):** `stripUnsupportedAssertions()` — scan pattern for `\b`, `\B`, `(?=`, `(?!`, `(?<=`, `(?<!`; strip `\b`/`\B` (remove 2 bytes), return `error.UnsupportedRegexAssertion` for lookaround. Best-effort transformation.

**Approach B (fallback):** When regex fails to compile, auto-retry with `regex = false` (literal substring).

**Recommendation:** A for Wave 2, B as fallback for remaining unsupported assertions.

**Testing:** Tests for `stripUnsupportedAssertions` covering `\b`, `\B`, `(?=`, plain patterns, patterns with `\\`.

**LOC:** ~40 lines grep.zig + ~50 lines test.

### 3.4 [🟡] Fix `catch return` → `try` — Wave 2

**Target:** `src/agent/loop.zig`, `src/agent/agent.zig`

**Approach:** Change `catch return` to `try` in functions where `errdefer` follows. If function return type is `!void`, `try` propagates error correctly and `errdefer` fires. If function is void, restructure to use `if (result) |val| { ... } else |err| return err;`.

**LOC:** ~5 lines changed.

### 3.5 [🟡] Replace manual `freeSessionHeader` with reflection — Wave 1

**Target:** `src/coding/session.zig`

**Approach:** Use `@typeInfo(SessionHeader).Struct.fields` to iterate fields at comptime and free each `[]const u8` field. Adding new string field → automatically freed. ~3 lines.

**Testing:** Create `SessionHeader`, free it, assert no leak (implicit via `std.testing.allocator`).

**LOC:** ~3 lines session.zig.

### 3.6 [🟡] Add mode-level integration tests — Wave 3

**Target:** `test/mode_test.zig` (merged file)

**Approach:** One test per mode:
1. **Print:** Spawn `franky --provider faux --mode print "hello"`, assert output contains expected faux-provider response.
2. **RPC:** Spawn subprocess, write JSON-RPC request on stdin, assert valid response.
3. **Proxy:** Start `franky --mode proxy`, poll `127.0.0.1:18787`, POST `/prompt`, assert `GET /transcript` returns valid JSON.

**LOC:** ~220 lines.

### 3.7 [🟡] Improve `nowMillis()` fallback — Wave 3

**Target:** `src/ai/stream.zig`

**Approach A (recommended):** Add `mach_absolute_time` fallback on Darwin — cannot fail. Low risk, no call-site changes, eliminates Darwin edge case entirely.

**LOC:** ~10 lines stream.zig.

### 3.8 [🟡] Replace manual `memcpy` in compaction with safe splice — Wave 3

**Target:** `src/coding/compaction.zig`

**Approach A (recommended):** Keep manual `memcpy` but add runtime assertion verifying copy bounds. Add unit tests for `replaceSpanWithSummary`: first N, last N, middle span, single message, removal only.

**LOC:** ~5 lines compaction.zig + ~40 lines test.

### 3.9 [🟡] Add partial-JSON parser test suite — Wave 3

**Target:** New `test/partial_json_test.zig` + minor export surface in `src/ai/partial_json.zig`

**Approach:** Focused tests: basic types, nested objects, arrays, string escapes, partial tokens byte-by-byte, tool-call shaped input, malformed input, empty input, DeepSeek-style input. Assert on parser internal state + final output.

**LOC:** ~150-200 lines test.

## 7. Implementation notes

### 7.1 Proxy shutdown
Add `fd: std.posix.fd_t` and `shutdown_on_close: bool = true` to `Subscriber`. In `fanOutLocked`, after `sub.closed.store(true, .release)`: `if (sub.shutdown_on_close) { std.posix.shutdown(sub.fd, .RECV) catch {}; }`.

### 7.2 Object store sweep assertion
In session.zig, before sweep: iterate transcript messages, for each `cb == .ref`, assert hash is in `keep` list (guarded by `builtin.mode != .ReleaseFast and builtin.mode != .ReleaseSmall`).

### 7.3 Grep regex stripping
Before regex compilation: `stripUnsupportedAssertions(pattern, temp_allocator)`; on `error.UnsupportedRegexAssertion` → fall back to `regex = false` literal search.

### 7.4 `freeSessionHeader` reflection
One-liner replacement using `@typeInfo` comptime iteration over struct fields.
