# LLM Agent Standards — Franky Support (Implemented Parts)

Collates portions of [v2.30 design](./v2.30-llm-agent-standards.md) that have been implemented. Remaining items in [v2.30-not-implemented.md](./v2.30-not-implemented.md).

## 1. Implemented: InstructionForest + AGENTS.md Loading (§4.2, §4.8)

**Files:** `src/coding/instructions.zig` (NEW), `src/coding/modes/print.zig`, `src/coding/config/cli.zig`

**What works:**
- `InstructionForest` scans `AGENTS.md`, `CLAUDE.md`, `.agents/agents.md` at workspace root and recursively in subdirectories (depth-limited 8 levels, max 50 files).
- `InstructionsState.scan()` returns forest + pre-rendered root-level block.
- `pickRootBlock()` precedence: `AGENTS.md` > `.agents/agents.md` > `CLAUDE.md` at same depth.
- `buildSystemPromptIo()` in print mode injects rendered instructions block after subagent hint, before skills section.
- `--no-standards` CLI flag suppresses instruction scanning.
- 6 tests: empty workspace, AGENTS.md only, CLAUDE.md only, AGENTS.md beats CLAUDE.md, `.agents/agents.md` content, multi-depth root-level picking.

**API:** `InstructionBlock` (source_path, content, kind, dir), `InstructionForest` (blocks, any_found), `InstructionsState` (forest, rendered, scan()).

**Known limitation:** `resolveClosest()` (per-file proximity resolution) returns `null` — only root-level block rendered at session start. Deferred to Phase 2.

## 2. Implemented: Skill Root Unification (§4.3, §4.6, §5)

**File:** `src/coding/skills.zig`

**What works:**
- `Roots.standard_roots` field holds additional skill directories from standard locations.
- `Roots.resolveStandard()` computes paths for: `<workspace>/.agents/skills/`, `<workspace>/.claude/skills/`, `<workspace>/.cursor/rules/`, `$FRANKY_HOME/.agents/skills/`, `$FRANKY_HOME/.claude/skills/`.
- Frontmatter extended with `id:` field (`.agents/skills/*/skill.md` uses `id:` when `name:` absent; `name` wins when both present, `id` stored as alias).
- Frontmatter extended with `enabled:` field (default `true`; `enabled: false` excluded from selection).
- Unknown frontmatter keys silently ignored (forward-compat).

**Skill root precedence:** `--skills <dir>` (CLI, highest) > `<workspace>/.franky/skills/` > `<workspace>/.agents/skills/` > `<workspace>/.claude/skills/` > `<workspace>/.cursor/rules/` > `<workspace>/skills/` > `$FRANKY_HOME/skills/` > `~/.agents/skills/` > `~/.claude/skills/`.

**Known limitation:** `.cursor/rules/` path scanned as skill root but no `parseCursorRule()` converter yet. Tracked in not-implemented doc.

## 3. Implemented: CLI Flags (§4.1, §5)

**File:** `src/coding/config/cli.zig`

- `--no-standards` — boolean; when set, `buildSystemPromptIo()` skips instruction scanning. Franky-native paths unaffected.
- `--agents <dir>` — parsed into `cfg.agents_path`. **Parsed but not yet wired** into scanning logic.

## 4. Current System Prompt Assembly Order (§4.8, partial)

In `buildSystemPromptIo()`: (1) Base system prompt, (2) `Current folder:` injection, (3) Subagent hint block, (4) **AGENTS.md / CLAUDE.md instructions** (new — v2.30), (5) Active skills section, (6) Review config block, (7) `--append-system-prompt` content (always last).

Not yet: `.agents/system-prompt.md` override, CLI `--system-prompt` override.
