## 🔴 Issue 2 — Stuck detector `resetState` leaks `pending_hint` (bug)

**File:** `src/agent/guardrails/stuck_detector.zig`, lines 214–221

`resetState()` clears `consecutive_count` and `last_*` fields but never clears `pending_hint`, `pending_tool_name`, or `pending_tool_code`. When model hits hint threshold (5 consecutive errors) then recovers, `resetState` fires but `pending_hint` stays `true` — stale hint injected on next `betweenTurns`.

**Fix:** Add `self.pending_hint = false;` and free pending strings.

## 🔴 Issue 3 — Event model `ErrorCode` variants are dead code

**Files:** `src/ai/errors.zig` (L65–66, 82–87, 155–156), `src/agent/guardrails/compilation_guard.zig` (L195), `src/agent/guardrails/stuck_detector.zig` (L188)

`ErrorCode.compilation_failed`, `ErrorCode.stuck_pattern`, `ErrorSource.guardrail`, `is_fatal: bool = true` exist in type system but never populated at runtime. Guardrails bypass `agent_error` and emit bare-string `tool_code` values instead.

**Decision:** Option A — Update guardrails to emit real `agent_error` events (typed enum, `source = .guardrail`, `is_fatal = false`). Option B — Update spec to say these are "future fatal escalation" (v2). → **Leaning A.**

## 🟡 Issue 4 — `setupAutoCommitBranch` uses timestamp instead of ULID

**File:** `src/agent/guardrails/guardrails.zig`, lines 93–94

Spec says `franky/<session-ulid>`; implementation uses `franky/{millisecond_timestamp}`. Two sessions in same ms share branch name; `git checkout -b` fails silently.

**Fix options:** (1) Append `getpid()`, (2) Accept `session_id` in `GuardrailState.Config`, (3) Short random suffix.

---

## 🟡 Issue 5 — `finish_task` clears state on compilation failure, preventing easy retry

**File:** `src/agent/guardrails/guardrails.zig`, lines 142–144

When final compilation guard fails, task state resets: `triggered` → false, `commit_message`/`summary` freed. Model must call `finish_task` again with fresh message — original commit message discarded.

**Suggestion:** Keep `commit_message` across retry, or inject previous message in compilation-failure hint.
